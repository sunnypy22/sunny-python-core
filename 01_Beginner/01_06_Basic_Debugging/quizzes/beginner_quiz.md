# Beginner Quiz - Basic Debugging

1. What does `print()` debugging mean?
2. Which error occurs when dividing by zero?
3. What is the purpose of `assert` statement?
4. In a traceback, where is the actual error usually shown?
**Answers**:
1. Adding print statements to see variable values
2. ZeroDivisionError
3. To check if a condition is True, otherwise raise AssertionError
4. At the bottom of the traceback
