# Beginner Quiz - String Manipulation
1. Strings in Python are:
   a) Mutable   b) Immutable
2. Which method removes whitespace from both ends?
   a) trim()   b) strip()   c) remove()   d) clean()
3. What does "hello".upper() return?
   a) "Hello"   b) "HELLO"   c) "hello"   d) Error
4. f-strings were introduced in which Python version?
   a) 3.5   b) 3.6   c) 3.7   d) 3.9
**Answers**: 1-b, 2-b, 3-b, 4-b
