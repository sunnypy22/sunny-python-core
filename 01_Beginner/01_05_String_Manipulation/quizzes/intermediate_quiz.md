
# Intermediate Quiz - String Manipulation
1. What is the difference between `find()` and `index()`?
2. Which is more efficient for concatenating many strings: `+` or `join()`?
3. What does `split()` do when called without arguments?
4. How do you check if a string contains only digits?
**Answers**:
1. find() returns -1 if not found, index() raises ValueError
2. join() is much more efficient
3. Splits on whitespace
4. Use isdigit()
