# Beginner Quiz - Modules and Packages

1. What is a module in Python?
   a) A folder  b) A .py file  c) A function  d) A package
2. Which is the correct way to import the math module?
   a) include math  b) import math  c) from math  d) load math
3. What does `import math as m` do?
   a) Renames the module to m  b) Imports only math functions  c) Creates alias
4. `from math import sqrt` means:
   a) Import entire math module  b) Import only sqrt function  c) Import all functions
5. What is the purpose of `__init__.py` file?
   a) To initialize variables  b) To make a folder a Python package  c) Both
**Answers**:
1-b, 2-b, 3-a & c, 4-b, 5-c
